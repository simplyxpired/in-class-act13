# In-Class Activity 13 - Firebase Authentication

## About the App

For this activity, I made a Flutter app using Firebase Authentication. The app lets users create an account, log in, change their password, and sign out.

## Features

- Create an account with an email and password
- Log in to an account
- See your email on the profile page
- Change your password
- Sign out
- Show error messages when something goes wrong

## Testing

I tested the app by making an account and checking Firebase to see if it was saved. I also tested logging in, changing my password, and signing out.

I tried entering the wrong password to make sure an error message would show up. I had a few problems at first, but I was able to fix them.


## What I Learned

I learned how to connect Firebase to Flutter and use it to handle user accounts. I also learned how the app checks if someone is logged in and how to update passwords.
